# Shiny.BluetoothLE.Hubs has moved

**This repository is archived.** Shiny.BluetoothLE.Hubs is now developed and released from
**[shinyorg/hubs](https://github.com/shinyorg/hubs)**, together with Shiny.UniversalHubs (the same hubs over Wi-Fi).

- Source: [`src/Shiny.BluetoothLE.Hubs*`](https://github.com/shinyorg/hubs/tree/v1/src)
- Issues and discussions: [shinyorg/hubs](https://github.com/shinyorg/hubs/issues)
- Documentation: https://shinylib.net/blehubs/
- NuGet: [Shiny.BluetoothLE.Hubs](https://www.nuget.org/packages/Shiny.BluetoothLE.Hubs). From 1.5, every
  Shiny.BluetoothLE.Hubs and Shiny.UniversalHubs package ships from shinyorg/hubs with one shared version.

The history up to 1.4.0 stays here.
